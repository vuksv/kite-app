Recorded sessions (FIT files straight from the watch) listed in `sessions.json`.
They contain the GPS track of each session - public, by the owner's choice, temporarily.
Add one with `python tools/add_session.py <file.zip|file.fit> "<label>"`; the site lists
them and opens each at `https://vuksv.github.io/kite-app/?fit=sessions/<name>.fit`.
